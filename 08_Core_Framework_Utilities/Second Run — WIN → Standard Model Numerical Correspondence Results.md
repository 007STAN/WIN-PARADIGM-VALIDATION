# Second Run — WIN → Standard Model Numerical Correspondence Results

## Experimental configuration

The second target-blind WIN → Standard Model correspondence run generated and evaluated:

- **3,000 WIN configurations**
- **50 top WIN configurations retained**
- **34 Standard Model targets evaluated**
- WIN configurations ranked using the WIN stability score **before** Standard Model comparison
- Multiple mathematical WIN projections evaluated against the Standard Model target bank

The purpose of this run was to determine whether independently generated WIN configurations contain numerical structures that correspond to known Standard Model dimensionless observables.

# Interpretation

The second run produces a direct numerical correspondence between the WIN-side configuration ensemble and the Standard Model target bank.

The most precise reported correspondence is:

\[
\boxed{
0.546000
\;\longleftrightarrow\;
0.546002
}
\]

for $\sin^2\theta_{23}$, with a reported difference of:

\[
\boxed{3.193284\ {\rm ppm}}.
\]

Other close correspondences include:

\[
\boxed{
0.007350
\;\longleftrightarrow\;
0.007350
}
\]

for $m_c/m_t$, with:

\[
\boxed{22.966275\ {\rm ppm}},
\]

and

\[
\boxed{
0.059464000000000
\;\longleftrightarrow\;
0.059461870075814
}
\]

for $m_\mu/m_\tau$, with:

\[
\boxed{35.818717\ {\rm ppm}}.
\]

The run therefore demonstrates that the tested WIN configuration/projection space contains numerous numerical correspondences with Standard Model observables, including several at sub-$10^{-3}$ relative error and some at the $10^{-5}$ level.

The numerical result itself is reported here without replacing the actual values with error-only summaries.

The next question is statistical and structural: whether the observed correspondence rate is greater than expected from the flexibility of the configuration/projection search, and whether the corresponding Standard Model structures can be derived from WIN without selecting them from Standard Model information.

Accordingly, this experiment should be described as a **target-blind numerical correspondence test**, not by itself as a first-principles derivation of the Standard Model.
